TpX drawing editor

Use the Insert menu or toolbar to choose a drawing primitive. Click to place points, or drag sized shapes such as circles and rectangles. Press Escape to cancel a drawing operation. Use the selection tool to select and move objects.

Properties and text

Select an object and open its properties to change line width, colors, fill, font size and alignment. Enter a complete math expression such as $(a+b)$ in a text object's text field, or use its TeX source field for other LaTeX code. The canvas displays editable text; LaTeX previews and exports typeset it.

Documents and export

Save editable drawings as .TpX. Use Undo and Redo to reverse changes. Export TikZ or SVG for use elsewhere. Writing TikZ source does not require TeX; typeset previews and LaTeX-derived PDF exports do. Install TeX and any required external converters separately, then configure their paths and preview viewers in Settings.

First scientific figure

  1. Choose File → New. Draw axes with Insert → Insert line and a curve with Insert → Insert curve; click its points and double-click to finish.
  2. Place a label with Insert → Insert text. Select it to edit its caption and enter a formula such as $f(x)=x^2-1$ as its TeX source. The caption remains editable on the canvas.
  3. Select an object to inspect its style and text properties in the Inspector. Choose Point coordinates… for point geometry; Object properties focuses the Inspector on the selection.
  4. Use File → Save as… (File → Download a copy as… in the browser), choose TikZ source, and save figure.tikz. Keep the .TpX document for native editing. TikZ save-back accepts supported edits and reports unsupported ones.
  5. Include the snippet in LaTeX with \usepackage{tikz} and \input{figure.tikz}, then compile with pdflatex. Debian/Ubuntu packages are texlive-latex-base and texlive-pictures.

Imported or refreshed TeX stays inert until View → Trust TeX preview for this document. Review native TeX source before trusting it: preview uses local LaTeX and dvipng; dvisvgm enables reusable SVG. The browser uses bundled MathJax for supported math text and does not invoke local tools. TikZ import is limited to 4 MiB, 500,000 tokens and 256 nested groups.

Bundled drawings: quadratic function · vector addition · double slit. Browser documents use a temporary file system in the current tab; File → Download a copy downloads a copy. Desktop File → Open Example opens an unsaved drawing, so Save asks for a destination and leaves the bundled example unchanged.

Keyboard and installation

Menus show the current shortcuts. On macOS, editing commands use Command; on Windows and Linux, they use Control. Text fields apply editing shortcuts to their text; return focus to the canvas to edit drawing objects.

The package's INSTALL.md explains installation, dependencies and Mac first launch. README.md contains drawing defaults, tool prerequisites and source build instructions. The bundled examples/README.md gives the full figure tutorial.
