About

TpX is a drawing program for LaTeX pictures, written with Lazarus. This page runs the unchanged LCL application compiled to WebAssembly (wasm32-wasip1) on the CustomDrawn widgetset’s WASI browser backend.

Built automatically from the latest TpX master against Lazarus MR !813 (browser backend) with MR !826 (masked image copies).

Desktop-only features such as LaTeX/MetaPost compilation and printing are unavailable here. Files stay in this browser until you download them.
